📦 Installation Guide

macOS
  1. Download the .dmg file from the GitHub Actions artifacts or releases.
  2. Open the DMG and drag Stagman into your Applications folder.
  3. On first launch, if macOS alerts about an unsigned developer, right-click Stagman in Applications and choose Open.
  4. Allow Keychain access when prompted so Stagman can securely store your tokens.
Windows
  1. Download the .msi installer or portable zip package.
  2. Run the installer and follow the prompt.
  3. If Windows SmartScreen appears, click More info → Run anyway.
Ubuntu / Linux
  1. Download the .deb or .AppImage package.
  2. For Debian/Ubuntu: sudo dpkg -i stagman_*.deb
  3. For AppImage: chmod +x Stagman-*.AppImage && ./Stagman-*.AppImage
