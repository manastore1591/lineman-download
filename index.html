📦 Installation Guide

Each package is listed with its SHA-256 hash in SHA256SUMS.txt. Download it next to your package and check the hash before installing; do not install a file whose hash does not match.

macOS
  1. Download the .dmg file and SHA256SUMS.txt into the same folder.
  2. Verify it in Terminal, from that folder: shasum -a 256 -c SHA256SUMS.txt --ignore-missing
    The .dmg must be reported as OK. (Or run shasum -a 256 Stagman_*.dmg and compare the hash with the one listed for it.)
  3. Open the DMG and drag Stagman into your Applications folder.
  4. Open Stagman from Applications. A signed and notarized build opens normally.
Fallback for unsigned builds only. The macOS build currently hosted on this page is not signed or notarized with an Apple Developer ID, so macOS may refuse to open it and say "Stagman is damaged and can't be opened". Only after the checksum above matches, either go to System Settings → Privacy & Security and click Open Anyway, or run in Terminal:
xattr -cr /Applications/Stagman.app
This recursively removes the quarantine attribute (and other extended attributes) that macOS adds to downloaded files. Gatekeeper then skips its check for that copy of the app, so you are relying only on the checksum and on this download page. Never use it on an app whose checksum you have not verified.
Windows
  1. Download the .exe setup or .msi installer and SHA256SUMS.txt.
  2. Verify it in PowerShell or Command Prompt: certutil -hashfile Stagman_0.1.0_x64-setup.exe SHA256 and compare the hash with the one listed for that file.
  3. Run the installer and follow the prompt.
  4. The Windows installer is not code-signed, so SmartScreen may warn. Only after the hash matches, click More info → Run anyway.
Ubuntu / Linux
  1. Download the .deb or .AppImage package and SHA256SUMS.txt.
  2. Verify it: sha256sum -c SHA256SUMS.txt --ignore-missing (or shasum -a 256 -c SHA256SUMS.txt --ignore-missing).
  3. For Debian/Ubuntu: sudo dpkg -i Stagman_*.deb
  4. For AppImage: chmod +x Stagman_*.AppImage && ./Stagman_*.AppImage
